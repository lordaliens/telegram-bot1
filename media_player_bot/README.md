# Telegram Media Player Bot (Voice Chat Streamer)

این ربات یک پخش‌کننده رسانه (موزیک و ویدیو) برای گروه‌های تلگرامی است که به صورت مستقیم فایل‌ها را در ویس‌چت (Voice Chat) استریم می‌کند.

## ویژگی‌ها
- جستجوی هوشمند ویدیوهای ترند یا خاص از طریق توصیف متنی با استفاده از Google Gemini.
- دانلود خودکار موزیک/ویدیو از منابع مختلف (یوتیوب، اینستاگرام و غیره) با کمک `yt-dlp`.
- پخش، مکث و توقف استریم در ویس‌چت با استفاده از دستورات فارسی (`پخش`، `مکث`، `توقف`) بدون نیاز به اسلش (`/`).
- قابلیت پخش فایل‌های آپلود شده در گروه (با ریپلای کردن روی فایل و نوشتن کلمه `پخش`).

## پیش‌نیازها
از آنجایی که ربات‌های تلگرام به تنهایی اجازه ورود به ویس‌چت را ندارند، این پروژه به یک "اکانت کمکی" (یوزربات) نیاز دارد.

- **Python 3.8+**
- **توکن ربات** (از @BotFather)
- **API_ID و API_HASH** (از my.telegram.org)
- **Session String** برای اکانت کمکی (تلگرام)
- **GEMINI_API_KEY** (اختیاری، برای جستجوی هوشمند با توصیف متنی)

## نصب و راه‌اندازی

1. نصب نیازمندی‌ها:
```bash
pip install -r requirements.txt
```

2. دریافت Session String:
برای دریافت سشن استرینگ پایتون را باز کرده و از کتابخانه pyrogram استفاده کنید (یا از ربات‌های تولید سشن معتبر استفاده کنید). دقت کنید که این سشن مربوط به اکانت کاربری شماست که باید در گروه‌ها عضو باشد تا بتواند ویس‌چت را مدیریت کند.

3. پیکربندی محیط:
فایل `.env.example` را به `.env` تغییر نام دهید و مقادیر مربوط به خودتان را در آن وارد کنید.

4. اجرای ربات:
```bash
python main.py
```

## نحوه استفاده در گروه
- ابتدا مطمئن شوید که ربات در گروه ادمین است (برای مدیریت پیام‌ها).
- اکانت کاربری کمکی نیز باید در گروه عضو باشد.
- یکی از ادمین‌ها ویس‌چت گروه را روشن کند.
- حال با ارسال دستور `پخش [نام آهنگ یا توصیف ویدیو]`، ربات شروع به کار می‌کند.
- با نوشتن `مکث`، استریم متوقف شده و با `ادامه` دوباره پخش می‌شود.
- با نوشتن `توقف`، دستیار از ویس‌چت خارج می‌شود.
